# beg_informat

Интерактивные уроки информатики (5–11 классы, тренажёры ЕГЭ/ВПР).

## Структура

- `lessons.html` — каталог уроков и личных результатов;
- `5-class/`, `6-class/`, `10-class/`, `ege-class/`, `python-class/` — уроки;
- `trainer/` — тренажёр экзаменационных заданий;
- `shared/` — общие скрипты и стили (`account.js`, `app.js`, `nav-auth.js`);
- `apps-script/` — бэкенд аккаунтов и результатов на Google Apps Script.

## Роли

| Роль | Страница после входа | Возможности |
|------|----------------------|-------------|
| Ученик (`student`) | `lessons.html` | уроки и свои результаты |
| Учитель (`teacher`) | `teacher.html` | прогресс классов из своей области доступа |
| Родитель (`parent`) | `parent.html` | прогресс привязанных детей |
| Администратор (`admin`) | `admin.html` | аккаунты, роли, все результаты |

Публичная регистрация создаёт только ученика. Привилегированные аккаунты
создаёт администратор в `admin.html`. Роль хранится в листе «Аккаунты» Google
таблицы и проверяется сервером при каждом защищённом запросе; значение в
`localStorage` используется только для выбора страницы после входа.

Подробности по настройке бэкенда и первом администраторе — в
[apps-script/README.md](apps-script/README.md).

## Обновление бэкенда

После изменения `apps-script/Code.gs` нужно заново развернуть веб-приложение
в Apps Script и один раз запустить `setup()` — он добавит недостающие колонки
`role` и `scope` без потери данных. Первого администратора назначают функцией
`makeAdmin('Имя Фамилия', 'Администрация')` в редакторе Apps Script.
